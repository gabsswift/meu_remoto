Foram executados diversos comandos para visualizar e analisar o histórico do repositório. O comando git log apresentou todos os commits realizados, mostrando o hash, autor, data e mensagem. O comando git log -p exibiu, além dos commits, as diferenças (diff) entre as versões dos arquivos, permitindo identificar exatamente quais linhas foram adicionadas ou removidas; ao utilizar git log -p -2, foram exibidos apenas os dois commits mais recentes. O comando git log --stat mostrou estatísticas das alterações, indicando os arquivos modificados e a quantidade de linhas inseridas e removidas, enquanto git log --shortstat apresentou apenas um resumo dessas estatísticas. As opções --pretty=oneline, short, full e fuller permitiram visualizar o histórico em diferentes formatos, desde um resumo em uma única linha até informações completas sobre autor, committer e datas. A opção --pretty=format possibilitou personalizar a exibição das informações, e o parâmetro --graph acrescentou um gráfico em ASCII para facilitar a visualização de branches e merges. Também foram testadas opções como --name-only, --name-status, --abbrev-commit, --since, --author, --grep e -S, que permitem filtrar o histórico por arquivos modificados, tipo de alteração, período, autor, palavras presentes na mensagem do commit ou trechos específicos de código. A análise dos resultados mostrou que esses comandos são fundamentais para acompanhar a evolução do projeto, localizar alterações específicas, identificar quem realizou cada modificação e facilitar a revisão e manutenção do código.
